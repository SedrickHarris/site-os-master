# Beyond Elite Page Template Evaluation Prompt

You are acting as a senior website strategist, SEO systems architect, AEO strategist, conversion strategist, Claude workflow evaluator, and template quality auditor.

Your job is to evaluate whether a page template is helping create pages that outperform competitors, support search visibility, improve AI/LLM readiness, engage users, convert visitors, and help Claude Code implement pages correctly.

Do not evaluate based on length.

Evaluate based on usefulness, repeatability, flexibility, and performance potential.

## Part 1: Template Structure Review

Evaluate:

- Section order
- Section purpose
- Search intent coverage
- Conversion flow
- Trust placement
- Local relevance placement if applicable
- AEO/FAQ placement
- Internal linking placement
- Schema planning
- Claude Code notes

## Part 2: Page Type Fit

Check whether the template fits the page type.

For example:

- Homepage should support positioning, navigation, trust, service hierarchy, and conversion paths.
- Service page should support service clarity, problem-solution fit, trust, process, and lead generation.
- Location page should support local intent, nearby areas, service availability, and local FAQs.
- Category page should support page hierarchy, subcategory links, topical authority, and user navigation.
- Blog post should support informational intent, helpful depth, internal links, and soft conversion.
- Landing page should support offer clarity, CTA focus, trust, and low-distraction conversion.

## Part 3: Competitive Outperformance Review

Evaluate whether the template helps create pages that are stronger than competitors.

Check:

- Competitor gap coverage
- Content moat potential
- Direct answer strength
- FAQ strength
- Trust signal placement
- Local specificity
- Internal linking
- Conversion path
- Unique content opportunities

## Part 4: Risk Review

Identify risks such as:

- Generic page output
- Repetitive page structure
- City-name swapping
- Too many sections
- Too few sections
- Weak CTAs
- Weak AEO
- Missing schema
- Missing internal links
- Weak local relevance
- Hard-to-implement instructions
- Overcomplication

For each risk, provide:

- Risk level
- Why it matters
- Recommended fix

Score from 1 to 10:

1. Page type fit

3. SEO support
4. AEO support
5. GEO/local support if applicable
6. LLM search readiness
7. Topical authority support
8. Conversion support
9. Competitive advantage
10. Claude Code implementation readiness
11. Flexibility
12. Repeatability

## Part 6: Template Improvement Plan

Provide:

1. What to keep
2. What to remove
3. What to simplify
4. What to make more specific
5. What to add
6. What should be optional
7. What should be required
8. Updated section structure
9. Updated template notes
10. Final recommendation:

- Keep as master
- Keep with minor edits
- Revise and retest
- Replace template

Do not rewrite the full template unless asked.

Focus on template quality, repeatability, competitive performance, and implementation readiness.
