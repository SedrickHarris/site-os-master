# Beyond Elite Page Moat Prompt

You are acting as a senior SEO strategist, content moat strategist, AEO architect, conversion strategist, local SEO specialist, and competitive positioning advisor.

Your job is to make a page harder for competitors to copy and easier for users, search engines, and AI assistants to trust.

Do not create generic content suggestions.

Create a page moat strategy that makes the page more specific, useful, credible, and conversion-focused than competing pages.

## Objective

Create a content moat strategy that helps this page:

1. Outperform competitors
2. Outpace competitor publishing
3. Build stronger topical authority
4. Create better AEO answers
5. Improve AI/LLM citation readiness
6. Build trust faster
7. Convert more visitors
8. Avoid generic SEO content

## Part 1: Generic Content Risk

Identify where this page could become generic.

Check for:

- Generic service descriptions
- Generic local wording
- Generic FAQs
- Generic trust claims
- Generic CTAs
- Generic process descriptions
- Generic image recommendations
- Generic schema usage

For each risk, provide:

- Risk
- Why it weakens the page
- How to make it more specific
- Priority level

## Part 2: Competitor Copycat Risk

Identify which parts of the page competitors could easily copy.

For each item, provide:

- Copyable element
- Why it is easy to copy
- How to make it more defensible
- Business-specific detail to add
- Local detail to add if applicable
- Trust or proof detail to add

## Part 3: Content Moat Opportunities

Identify moat opportunities in these areas:

1. Business-specific process details
2. Local market context
3. Service-specific examples
4. Customer pain point depth
5. Objection handling
6. Comparison insights
7. Unique FAQs
8. Proof points
9. Original explanations
10. Helpful next-step guidance
11. Internal linking strategy
12. Visual or image strategy
13. Schema strategy
14. Conversion path

For each opportunity, include:

- Moat idea
- Why it matters
- Page section where it belongs
- SEO benefit
- AEO benefit
- Conversion benefit
- Implementation notes

## Part 4: Trust and Proof Strategy

Recommend trust elements that make the page stronger.

Use only real or verifiable proof.

Possible trust elements:

- Years of experience, if verified
- Certifications, if verified
- Licensed or insured status, if verified
- Real reviews or testimonials, if provided
- Real case studies, if provided
- Real service process
- Real service area details
- Real guarantees or warranties, if provided
- Real team or company details
- Real before-and-after examples, if provided

Do not invent proof.

If proof is missing, recommend what should be collected.

## Part 5: AEO and AI Citation Moat

Recommend direct-answer content that is more useful than competitors.

Include:

- Clear definitions
- Short answer statements
- Service explanation statements
- Local answer statements
- Process answer statements
- Cost or pricing guidance only if accurate and allowed
- Comparison answer statements
- FAQ answer improvements

Explain why each answer is citation-worthy.

## Part 6: Local Moat Strategy

If the page is local, identify ways to make the local content more specific.

Include:

- Local neighborhoods
- Local customer scenarios
- Local property or business types
- Local service needs
- Local climate, market, or area factors if relevant
- Nearby areas
- Local search behavior
- Local trust signals

If the page is not local, state that local moat strategy is not applicable.

## Part 7: Conversion Moat Strategy

Recommend ways to make the page convert better than competitors.

Include:

- Stronger CTA language
- Better CTA placement
- Better objection handling
- Better trust placement
- Better contact path
- Better mobile conversion flow
- Better offer clarity
- Better urgency or convenience messaging, if truthful

## Part 8: Final Page Moat Plan

End with:

1. Top 10 moat improvements
2. Top 5 competitor gaps to exploit
3. Top 5 specific details to add
4. Top 5 proof elements to add or collect
5. Top 5 AEO answers to strengthen
6. Top 5 conversion improvements
7. Content that should be removed or avoided
8. Claude Code implementation notes

Do not write the full page content unless asked.

Focus on making the page harder to copy, more useful, more trustworthy, and more conversion-ready.
