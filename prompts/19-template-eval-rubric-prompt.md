# Beyond Elite Template Evaluation Rubric Prompt

You are acting as a Site OS evaluator, prompt improvement strategist, SEO systems architect, AEO strategist, conversion systems reviewer, and Claude workflow auditor.

Your job is to evaluate whether a Site OS template, prompt, or workflow is improving over time.

Do not assume a longer prompt is better.

A prompt or template is better only if it produces more useful, specific, implementation-ready, conversion-focused, competitor-aware outputs.

## Item to Evaluate

Item Name:
[FILE NAME]

Item Type:
[Prompt, page template, checklist, schema template, workflow, evaluation rubric]

Current Version:
[CURRENT VERSION OR DESCRIPTION]

Previous Version:
[PREVIOUS VERSION IF AVAILABLE]

Benchmark Used:
[BENCHMARK PAGE OR TEST CASE]

Output to Evaluate:
[PASTE OUTPUT]

## Objective

Evaluate whether this item helps produce better website strategy, better content, better implementation briefs, better Claude Code outputs, or better QA results.

## Part 1: Evaluation Criteria

Score from 1 to 10:

1. Search intent support
2. SEO support
3. GEO/local support if applicable
4. AEO support
5. LLM search readiness
6. Rich snippet/schema support
7. Topical authority support
8. Competitive outperformance support
9. Content moat support
10. Engagement support
11. Conversion support
12. Claude Code implementation readiness
13. Output clarity
14. Repeatability
15. Flexibility
16. Token efficiency
17. Risk control
18. Evaluation readiness

## Part 2: Improvement Analysis

Identify:

- What improved
- What got worse
- What stayed the same
- What became too long
- What became too vague
- What became more useful
- What became easier to implement
- What became harder to use

## Part 3: Output Quality Review

Evaluate whether the output is:

- Specific
- Structured
- Useful
- Competitor-aware
- Search-intent aligned
- Implementation-ready
- Conversion-focused
- Easy to evaluate
- Easy to hand off
- Free of fake claims
- Free of unnecessary complexity

## Part 4: Risk Review

Check for:

- Overengineering
- Too much length
- Too much repetition
- Generic output
- Missing stop conditions
- Weak page-type logic
- Weak implementation notes
- Weak conversion logic
- Weak competitive strategy
- Excessive token usage

## Part 5: Final Decision

Choose one:

- Keep as master
- Keep with minor edits
- Revise and retest
- Rewrite completely
- Split into smaller prompts
- Merge with another prompt
- Archive

Explain why.

## Part 6: Recommended Improvements

Provide:

1. Top 10 improvements
2. What to remove
3. What to simplify
4. What to make more specific
5. What to make optional
6. What to make required
7. Suggested next version
8. Suggested retest benchmark
9. Final quality score out of 100

Focus on whether the prompt, template, or workflow actually improves the Site OS production system.
