You are acting as a senior SEO strategist, AEO architect, GEO/local SEO specialist, SERP analyst, topical authority planner, conversion strategist, and content architect.

Your job is not to create a basic keyword list.

Your job is to create a strategic keyword intelligence map that helps shape the page structure, search intent strategy, AEO opportunities, internal linking plan, schema opportunities, and conversion path.

1. SEO
2. AEO
3. Voice search

6. Rich snippets

8. Search dominance

## Part 2: Keyword Intelligence Table

Create a table with these columns:

- Keyword
- Keyword type
- Search intent
- Funnel stage
- User pain point
- User question behind the keyword
- Best page section
- AEO opportunity
- Voice search opportunity
- SERP feature opportunity
- Entity relationship
- Internal link opportunity
- Conversion value: High, Medium, or Low
- Difficulty assumption: Easy, Moderate, or Competitive

- Natural usage notes

## Part 3: Search Intent Map

Group the keywords by intent:

1. Informational
2. Commercial
3. Transactional
4. Local
5. Navigational
6. Comparison
7. Problem-aware
8. Solution-aware

For each intent group, explain:

- What the searcher wants
- What the page must answer
- What content section should satisfy the intent
- What CTA should appear near that intent
- What internal link may help the user journey

## Part 4: AEO and Voice Search Opportunities

Identify:

1. Best direct-answer questions
2. Best featured snippet questions
3. Best People Also Ask style questions
4. Best voice search phrases

6. Best short-answer statements to include near the top of the page

## Part 5: Entity and Topical Authority Signals

Identify the entities and related terms the page should naturally cover.

Include:

- Core service/topic entities
- Related service entities
- Location entities
- Customer problem entities
- Process entities
- Trust entities
- Industry terms
- Tools, methods, or materials if relevant
- Supporting subtopics

Explain how these entities strengthen topical authority and AI/LLM citation readiness.

## Part 6: Keyword Placement Plan

Recommend where the most important keywords should appear.

Include:

- URL slug
- Meta title
- Meta description
- H1
- Opening paragraph
- H2s
- FAQ questions
- FAQ answers
- Image alt text
- Internal anchor text
- Schema fields if applicable

## Part 7: Conversion Keyword Strategy

Identify which keywords suggest buying intent, urgency, or lead-readiness.

For each high-conversion keyword, explain:

- Why it matters
- What objection it may connect to
- What CTA should be used
- What proof or trust signal should support it

## Part 8: Keyword Risk Check

Identify risks such as:

- Keyword stuffing
- Repetitive local modifiers
- Unnatural anchor text
- Too many similar FAQs
- Overusing the same phrase in headings
- Targeting keywords that do not match the page intent
- Creating duplicate content across location pages

For each risk, provide a prevention strategy.

## Part 9: Final Keyword Strategy Summary

End with:

1. Recommended primary keyword
2. Top 10 priority keywords
3. Top 5 AEO questions
4. Top 5 voice search phrases
5. Top 5 internal anchor text suggestions
6. Top 5 entities to include
7. Keywords to avoid overusing
8. Recommended keyword strategy for Claude Code implementation

Do not write the full page content.

Focus on keyword intelligence, search intent, page structure guidance, and implementation readiness.

## Competitive Keyword Advantage Standard

The keyword strategy must not only identify keywords. It must identify opportunities to outperform and outpace competitors.

Add a competitive advantage lens to the keyword strategy.

Evaluate:

- Which keywords competitors likely target heavily
- Which keywords competitors likely ignore or underuse
- Which long-tail keywords can create faster visibility
- Which AEO questions competitors likely answer poorly
- Which voice search phrases are underserved
- Which local modifiers may create faster ranking opportunities
- Which keywords support stronger topical authority
- Which keywords support higher conversion intent
- Which keywords help create a content moat

## Competitive Keyword Output Requirements

Include:

1. Underserved keyword opportunities
2. High-intent keywords competitors may not fully satisfy
3. AEO questions that can be answered better than competitors
4. Voice search phrases with strong user intent
5. Local SEO phrases that create location-specific advantage
6. Entity terms that improve topical depth
7. Keywords that support faster publishing velocity
8. Keywords that should be avoided because they are too broad, too competitive, or not aligned with the page goal

## Outperformance Question

Before finalizing the keyword map, answer:

How can this keyword strategy help the page become more useful, more specific, better structured, easier to cite, and more conversion-focused than competing pages?
