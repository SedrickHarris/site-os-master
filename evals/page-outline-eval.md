# Page Outline Prompt Evaluation

Use this evaluation to grade outputs from:

prompts/02-page-outline-prompt.md

The goal is to determine whether the page outline prompt creates a complete, strategic, competitor-aware, implementation-ready page blueprint.

## Evaluation Score

Score the output from 0 to 100.

## Page Outline Evaluation Criteria

### 1. Page Strategy Clarity - 10 Points

The output should clearly define:

- Page type
- Page goal
- Target audience
- Search intent
- Primary CTA
- Secondary CTA
- Conversion path
- Recommended route or slug

### 2. Section Strategy Quality - 10 Points

Each section should include:

- Section goal
- Search intent supported
- Keyword/entity focus
- User question answered
- Content angle
- Conversion purpose
- Trust signal
- Claude Code notes

### 3. Search Intent Coverage - 10 Points

The outline should satisfy:

- Informational intent
- Commercial intent
- Transactional intent
- Local intent if applicable
- Problem-aware intent
- Solution-aware intent
- Decision-stage intent

### 4. SEO and Entity Strength - 10 Points

The outline should include:

- Primary keyword placement
- Secondary keyword support
- Entity coverage
- Supporting subtopics
- Metadata recommendations
- Heading strategy
- Image alt text guidance

### 5. AEO and Voice Search Strength - 10 Points

The outline should include:

- Quick answer section
- Direct answer statements
- FAQ strategy
- Voice search phrases
- People Also Ask style questions
- AI/LLM citation opportunities

### 6. GEO and Local Specificity - 10 Points

If the page is local, the outline should include:

- Local relevance
- Nearby areas
- Local pain points
- Local service needs
- Unique local content angles
- Avoidance of generic city-name swapping

If the page is not local, it should clearly state that GEO is not applicable.

### 7. Competitive Outperformance - 10 Points

The outline should identify:

- Competitor content gaps
- Better section opportunities
- Better direct answers
- Better FAQs
- Better trust signals
- Better local specificity
- Better conversion flow
- Content moat opportunities

### 8. Internal Linking and Schema Planning - 10 Points

The outline should include:

- Outbound link opportunities
- Inbound link opportunities
- Natural anchor text notes
- Schema types
- Schema fields needed
- Schema risks to avoid

### 9. Conversion Quality - 10 Points

The outline should include:

- Above-the-fold CTA
- Mid-page CTA
- Final CTA
- Objection handling
- Trust elements
- Lead capture path
- Mobile conversion considerations

### 10. Claude Code Readiness - 10 Points

The outline should be easy to turn into a Claude Code prompt.

It should include:

- Page sections
- Route
- Metadata
- Schema
- Internal links
- Image needs
- Component or layout notes
- QA expectations
- Guardrails

## Common Weaknesses to Watch For

- Generic section names without strategy
- Thin local relevance
- Too many repeated sections
- Weak FAQ strategy
- Missing internal links
- Missing schema
- Missing CTA logic
- No competitor outperformance plan
- No Claude Code implementation notes
- Too much content writing before strategy is approved

## Evaluation Output Format

Return:

1. Overall score out of 100
2. Category-by-category score
3. Strongest parts of the output
4. Weakest parts of the output
5. Missing strategic elements
6. Over-optimization risks
7. Competitor outperformance gaps
8. Claude Code readiness issues
9. Recommended prompt improvements
10. Final decision:

- Keep as master
- Keep with minor edits
- Revise and retest
- Rewrite completely
