# Site OS Prompt Evaluation Rubric

Use this rubric to evaluate whether a Site OS prompt produces outputs that are strategic, useful, implementation-ready, and designed to outperform competitors.

The goal is not to judge whether the output is long.

The goal is to judge whether the output is better, clearer, more specific, more strategic, and easier to use.

## Scoring System

Each prompt output should be scored from 0 to 100.

Use this scale:

- 90 to 100: Master-level output. Ready to keep as the current best version.
- 80 to 89: Strong output. Minor refinements needed.
- 70 to 79: Usable output. Needs improvement before becoming a master version.
- 60 to 69: Weak output. Major revisions needed.
- Below 60: Not acceptable. Prompt should be rewritten.

## Universal Evaluation Criteria

Score every major prompt output against these categories.

### 1. Search Intent Alignment - 10 Points

Evaluate whether the output clearly understands:

- What the searcher wants
- What problem they are trying to solve
- Their stage in the buyer journey
- What the page must answer quickly
- What would make the user bounce

### 2. SEO Strategy Strength - 10 Points

Evaluate whether the output supports:

- Primary keyword targeting
- Secondary keyword support
- Natural keyword placement
- Helpful headings
- Metadata planning
- Topical depth
- Search visibility

### 3. AEO and Voice Search Readiness - 10 Points

Evaluate whether the output includes:

- Direct answer opportunities
- Question-based structure
- Short answer statements
- Voice-search-friendly phrasing
- FAQ opportunities
- AI/LLM citation readiness

### 4. GEO and Local Relevance - 10 Points

Evaluate whether the output includes local relevance when applicable:

- Target location
- Nearby areas
- Local customer problems
- Local service needs
- Natural local language
- Avoidance of city-name swapping
- Local trust signals

If the page is not local, score this based on whether the prompt correctly identifies GEO as not applicable.

### 5. Competitive Outperformance - 10 Points

Evaluate whether the output helps the page outperform competitors through:

- Competitor gap identification
- Stronger content angles
- Better FAQs
- Better local specificity
- Better trust signals
- Better conversion path
- Content moat opportunities

### 6. Entity and Topical Authority - 10 Points

Evaluate whether the output identifies:

- Core entities
- Related entities
- Problems
- Services
- Locations
- Processes
- Trust signals
- Supporting subtopics
- Semantic relationships

### 7. Internal Linking Strategy - 10 Points

Evaluate whether the output includes:

- Relevant outbound internal links
- Inbound link opportunities
- Natural anchor text
- User journey purpose
- Topical authority purpose
- Conversion purpose
- Link quality over link quantity

### 8. Schema and Technical SEO Readiness - 10 Points

Evaluate whether the output includes:

- Recommended schema types
- Required fields
- Optional fields
- Metadata notes
- Breadcrumb opportunities
- FAQ schema opportunities
- Warnings against fake or unsupported data

### 9. Conversion Strategy - 10 Points

Evaluate whether the output supports:

- Clear CTA path
- Above-the-fold CTA
- Mid-page CTA
- Final CTA
- Objection handling
- Trust building
- Mobile conversion flow
- Lead capture clarity

### 10. Claude Code Implementation Readiness - 10 Points

Evaluate whether the output is ready to be used for implementation.

Check whether it includes:

- Route or slug
- Page sections
- Content requirements
- Metadata requirements
- Schema requirements
- Internal links
- Image requirements
- Guardrails
- QA expectations
- Acceptance criteria

## Failure Flags

Deduct points if the output:

- Is generic
- Repeats the same idea too often
- Creates keyword stuffing risk
- Invents fake claims, reviews, ratings, credentials, pricing, or proof
- Ignores search intent
- Creates too many unnecessary sections
- Overcomplicates a simple page
- Does not provide implementation guidance
- Does not support conversion
- Does not help outperform competitors

## Final Evaluation Output Format

When evaluating a prompt output, return:

1. Overall score out of 100
2. Score by category
3. What worked well
4. What was weak
5. What should be improved
6. What should not be changed
7. Risk flags
8. Recommended prompt revision
9. Retest recommendation
10. Final decision:

- Keep as master
- Keep with minor edits
- Revise and retest
- Rewrite completely
