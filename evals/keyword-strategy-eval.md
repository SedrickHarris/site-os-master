# Keyword Strategy Prompt Evaluation

Use this evaluation to grade outputs from:

prompts/01-keyword-strategy-prompt.md

The goal is to determine whether the keyword strategy prompt creates a useful keyword intelligence map that shapes page structure, AEO opportunities, topical authority, internal linking, and conversion.

## Evaluation Score

Score the output from 0 to 100.

## Keyword Strategy Evaluation Criteria

### 1. Keyword Category Coverage - 10 Points

The output should include:

- Primary keyword
- Secondary keywords
- Long-tail keywords
- Local SEO keywords if applicable
- AEO question keywords
- Voice search keywords
- Transactional keywords
- Informational keywords
- Comparison keywords
- Problem-aware keywords
- Solution-aware keywords
- Entity-based terms

### 2. Search Intent Accuracy - 10 Points

The output should correctly map keywords to:

- Informational intent
- Commercial intent
- Transactional intent
- Local intent
- Comparison intent
- Problem-aware intent
- Solution-aware intent
- Funnel stage

### 3. AEO and Voice Search Opportunity - 10 Points

The output should identify:

- Direct-answer questions
- Featured snippet questions
- People Also Ask style questions
- Voice search phrases
- Near-me phrases if applicable
- Short answer statements

### 4. Competitive Keyword Advantage - 10 Points

The output should identify:

- Underserved keywords
- High-intent terms competitors may miss
- Easier long-tail opportunities
- Weak competitor FAQ opportunities
- Faster visibility opportunities
- Keywords that help build a content moat

### 5. Entity and Topical Authority Strength - 10 Points

The output should include:

- Core entities
- Related entities
- Service or topic entities
- Location entities
- Problem entities
- Process entities
- Trust entities
- Supporting subtopics

### 6. Keyword Placement Strategy - 10 Points

The output should recommend keyword placement for:

- URL slug
- Meta title
- Meta description
- H1
- Opening paragraph
- H2s
- FAQs
- Image alt text
- Internal anchor text
- Schema fields

### 7. Conversion Keyword Strategy - 10 Points

The output should identify:

- High-intent keywords
- Urgency keywords
- Buying-intent keywords
- Lead-readiness signals
- CTA alignment
- Objections connected to keywords

### 8. Internal Linking Support - 10 Points

The output should include:

- Anchor text suggestions
- Related page opportunities
- Topical authority links
- Conversion links
- User journey links

### 9. Risk Control - 10 Points

The output should warn against:

- Keyword stuffing
- Overusing exact-match keywords
- Repetitive local modifiers
- Weak broad keywords
- Keywords not aligned with the page goal
- Duplicate content risk

### 10. Implementation Readiness - 10 Points

The output should be usable for the next workflow step.

It should clearly support:

- Page outline creation
- Metadata creation
- FAQ creation
- Internal linking
- Schema planning
- Claude Code implementation

## Evaluation Output Format

Return:

1. Overall score out of 100
2. Category-by-category score
3. Strongest keyword opportunities
4. Weakest areas
5. Missing keyword categories
6. Missed competitive opportunities
7. Risk flags
8. Recommended prompt improvements
9. Retest recommendation
10. Final decision:

- Keep as master
- Keep with minor edits
- Revise and retest
- Rewrite completely
