# Benchmark Test Pages

Use these benchmark pages to test whether Site OS prompts improve over time.

Run old and new prompt versions against the same benchmark so the results can be compared fairly.

## Benchmark 1: Local Service Page

Business Name:
Pit Stop Junk Removal

Page Type:
Service page

Service:
Furniture and Appliance Junk Removal

Target Location:
Las Vegas, NV

Target Audience:
Homeowners, renters, landlords, property managers, and small businesses that need bulky items removed.

Primary CTA:
Request a quote

Primary Goal:
Generate junk removal quote requests.

Competitive Goal:
Create a page that is more specific, helpful, locally relevant, AEO-ready, and conversion-focused than typical junk removal service pages.

Evaluation Focus:

- Search intent
- Local relevance
- Service clarity
- Problem depth
- Trust signals
- AEO FAQs
- Internal links
- Schema
- Conversion path
- Content moat
